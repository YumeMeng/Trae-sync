# Trae Sync UI 原型评审与扩展边界

状态：方案 D 已确认作为 V1 UI 基础；正式规格已吸收交互与扩展边界。

## 1. 结论

方案 D 作为 V1 主界面基础：以历史库为日常入口，把选择与内容浏览放在同一工作区；同步计划作为右侧上下文区域；真正写入前才进入五阶段安全流程。

原型代码是一次性验证代码，不得直接提升为生产架构。生产实现只吸收本文的信息结构和交互结论。

## 2. 默认任务流

1. 用户进入历史库，先看到已收录账号、项目、对话和当前目标账号。
2. 用户按账号和项目浏览；复选框只负责选择，标题只负责打开内容预览。
3. 同步计划立即区分可同步项、已在目标账号中的内容和需要处理的排除项。
4. 界面同时显示“已选择”和“本次可同步”，两者不混用。
5. 用户点击“检查并安全同步”，进入确认变化、创建备份、应用、验证和完成流程。
6. 操作完成后进入操作与备份页查看证据；失败时不得显示部分成功。

自动查找默认关闭。手工查找由用户明确触发；任何数据库写入仍需单独确认。

## 3. 信息取舍

主界面只保留四类高频信息：历史范围、当前内容、同步计划、当前目标。数据库参数、加密参数和恢复策略不进入主界面。

当前账号在标题栏和同步计划中重复显示是有意的安全复核：前者表达当前环境，后者表达即将写入的目标。其他重复统计和重复导航应删除。

“历史库”既是浏览入口也是选择入口，不再单独设置内容重复的“同步”首页。同步是针对当前选择执行的动作，不是另一个信息空间。

## 4. 生产模块边界

```text
App Shell
  |- History Catalog UI
  |- Operation and Backup UI
  |- Settings UI
  |- Account UI                 future
  `- Automation UI              future

Application Use Cases
  |- ScanHistory
  |- BrowseHistory
  |- BuildSyncPlan
  |- ExecuteSyncPlan
  |- RestoreOperation
  |- SwitchAccount              future
  `- RunAutomationPolicy        future

Domain and Infrastructure
  |- Catalog
  |- Sync Planning
  |- Operation Runner
  |- Account Provider           future
  |- Automation Policy          future
  `- Product Adapter
```

历史库不负责账号切换；账号模块不直接修改历史数据库；自动化模块不绕过同步计划、备份和验证。跨模块功能由应用协调层组合已有用例。

## 5. 后续功能组合方式

### 账号切换

账号模块只完成账号识别和切换，并发布结果。协调层在切换成功后重新取得目标证据，再决定是否生成同步计划。

```text
SwitchAccount
  -> AccountChanged
  -> DetectTargetEvidence
  -> BuildSyncPlan
  -> UserConfirmation or EnabledPolicy
  -> ExecuteSyncPlan
```

同步模块不依赖某个具体账号管理工具。未来可以接入内置账号管理、现有外部工具或其他平台 Adapter。

### 自动绑定历史

自动化只保存用户选择的触发策略，例如“账号切换成功后提示同步”或“明确开启后自动生成计划”。它调用与手工操作相同的 `BuildSyncPlan` 和 `ExecuteSyncPlan`，不能拥有数据库直写通道。

数据库写入、强制备份、目标复核和完整验证不可被自动化配置关闭。自动化开关默认关闭。

### 新平台

平台差异由 `ProductAdapter` 吸收。历史浏览、范围选择、计划预览和操作记录使用稳定领域对象，不根据平台名称分支。新增 TRAE IDE 时增加 Adapter 和能力声明，不复制整套 UI。

## 6. 扩展 UI 位置

- 新增账号管理：左侧持久导航增加独立入口；当前账号仍由标题栏显示。
- 新增账号切换后同步：放在账号操作完成后的协调流程，不塞入历史库组件。
- 新增自动化：设置页增加一个默认关闭的入口，复杂规则进入次级页面。
- 新增平台：标题栏提供平台上下文切换；不把平台差异暴露成大量主界面设置。
- 新增诊断或恢复：归入操作与备份，不占用日常历史浏览空间。

## 7. 禁止的耦合

- UI 组件拼接 SQL、文件路径或加密参数。
- 账号切换完成后直接写 TRAE 数据库。
- 自动化绕过不可变同步计划或用户已确认策略。
- 平台 Adapter 决定是否跳过备份、验证或恢复。
- 为未来功能提前暴露大量空设置和无效按钮。
