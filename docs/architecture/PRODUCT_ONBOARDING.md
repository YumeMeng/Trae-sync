# 产品接入与现有产品迁移检查

> ADR-0034 的执行检查；2026-09-30。本期只接 Work CN 与 Trae CN，不预建其他产品实现。
> 2026-10-01 Phase 14 的最小操作/提交契约与依据追踪见 [PRD](../../.scratch/phase14-prd-20261001.md)，具体子票依赖/文件责任见 `tickets.new.md`。后端操作快照为唯一验收事实源；UI 快照不替代写前重新校验。
> 当前执行状态：Phase 14 独立评审已返回且用户授权持续实施；按 tickets 子票和 `.scratch/phase14-execution-review-20261001.md` 推进。Trae CN 原生认证/隔离事实仍只阻塞 P14-8b/8c 与其生产验收，不阻塞其他票。此处是后续产品接入检查，不是全期开工门禁。
> 本清单描述新产品应走的目标流程，不代表当前 Work/CN 的每个业务域都已使用统一适配器；现状与未迁移边界见 [模块地图](MODULE_MAP.md)。

1. **确认事实与范围。** 读取当前 ADR 状态链、模块矩阵和操作计划。记录本产品官方安装/数据路径、进程身份、OAuth client、凭据根、账号注册表、DB 与原生认证实际消费方式。字段同名不是兼容证据。未知事实先只读调查；操作是否支持、是否实现、是否验收分别记录。
2. **复用边界。** 沿用产品注册表、Account Adapter、Library 引用与现有 domain/ports/application/infrastructure/commands。新增产品差异留在协议、路径、原生认证/进程及 DTO 映射；共用页面、确认、通知、进度、签到结果判定和库规则。已有流程迁移保持前后可调用，每片绿后再移下一片，删除本片产生的孤立代码；不要求先做大规模目录移动。
3. **接通只读完整路径。** UI → IPC → 编排/规则 → 本产品适配器 → 本产品实际状态，写下所有 caller 与测试。后端未知上下文拒绝；前端延迟结果按产品/库/代次生效，事件/通知保留来源。保持五页导航，区块诚实说明；不支持的操作隐藏，缺证据的操作待验收。
4. **验证副作用边界。** 匹配产品 exe 与数据根；枚举/解析/身份未知时拒绝危险写。写前校验目标账号、凭据代次及本产品身份。复用同目录串行边界、备份、原子文件发布及数据库事务；回执表达提交、验证、恢复与启动的实际阶段。验证失败不能被包装成已回滚或可安全重复。
5. **隔离验证新行为。** 使用临时目录/合成数据与注入失败，证明不会改另一产品、选错账号、提交后单独回滚 auth 或跨页执行旧意图。CN 原生激活先独立确认官方消费身份及重启保持，首片不主动改历史；库整理沿用独立用户动作与验收，不附着切号自动执行。
6. **真实验收后开放操作。** 只读证据先取；真实 OAuth、生产切换、破坏性库操作与领取按对应用户动作及单次确认执行。每操作记录日期、代码/协议版本、脱敏身份、备份/结果及失败证据。mock、HTTP 200、工具指针、access 健康均不能替代官方目标身份或真实领取结果。未通过的操作保持 pending，不妨碍已经验收的读取/健康等能力。
7. **完成决策链与回归。** 更新能力证据、模块矩阵、ADR 实施状态、CONTEXT 与 tickets；验证生成命令清单及实际调用契约。按变更运行定向测试，每个集成批次做四套件门槛；真机结果单列。不得使用历史绿灯代替当前验收，也不得在无新变更/失败时反复全量测试。

最小回归集合：Work 账号保存/OAuth 取消、健康与同设备续期、HTTP 签到、主库/副环境切号、归档冻结与恢复、插件增删/切号 fail-soft、备份保留与凭据同 stamp、远程设备本机保护；产品往返切换不触发错误 IPC、显示旧详情或执行旧操作。

若某一步发现协议或恢复方式没有可信事实，继续完成不依赖该事实的准备与只读核对，记录阻塞操作与所缺证据，不猜写生产认证或宣布整期完成。范围/架构出现实质冲突时先更正文档；真实操作的执行点确认保留。离线实现遵循用户当前明确设定的评审/开工顺序；已有授权范围内不重复询问整体目标。
