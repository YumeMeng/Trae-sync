# UI 方向：高级、克制、信息优先（v1）

> 配套 `UI-CHARTER.md` 使用。宪章管"结构与预算"，本文件管"长相与语气"。
> 一句话：**用数字和留白说话，不用文字堆砌。**

## 1. 气质定义

- **安静**：颜色只在"有事"时出现；正常状态全部中性
- **留白**：用间距建立层级，不靠边框、分割线、卡片套卡片
- **数字优先**：能用一个数字表达的，不写一句话
- **一个主行动**：每屏只有一个主按钮，其余降级为次要或图标

## 2. 文字预算（硬限制，评审按此打回）

| 层级 | 上限 | 示例 |
|---|---|---|
| 页面标题 | 8 字 | 总览 / 账号 / 签到 |
| 区块标题 | 10 字 | 签到与账号 |
| 字段标签 | 6 字 | 今日签到 / 剩余积分 |
| 状态说明 | 25 字 | 未登录 |
| 单行正文 | 30 字（约 480px）| — |

**禁止**：段落式说明、帮助文案、"请注意 / 您可以…"、感叹号、日志式输出上界面。

## 3. 数字与标签

- 指标：数值 32px/600，标签 12px/中性；数值与标签上下排列
- 表格：行高 44px，数字列右对齐，字体 `tabular-nums`
- **≥3 条同类信息必须用表格或列表**，禁止用句子罗列
- 金额/积分保留 1 位小数；百分比保留整数

## 4. 颜色（只允许三种语义）

| 颜色 | 用途 |
|---|---|
| 中性（tokens）| 文字、背景、分割 |
| 靛蓝 `#4F46E5` | 可操作、当前选中 |
| 琥珀 | 需要处理（非错误）|
| 红 | 错误 / 阻断 |

**禁止绿色"成功"态**——正常就是用中性表达；页面里出现颜色 = 有事要处理。

## 5. 六页统一布局模式

```
页面 = 摘要条（3–5 个指标）
     + 主体（表格 / 列表 / 卡片栅格）
     + 主行动（右上角，或底部固定条）

详情 = 左侧身份卡（名称 / 状态 / 头像）
     + 右侧分区（≤ 3 组）

设置 = 分组卡片（每组 ≤ 5 项，每项一行：标签 + 控件）

空态 = 图标 24 + 一句结论（≤ 20 字）+ 一个按钮

加载 = 骨架屏；不出现"加载中…"文字
```

## 6. 间距与视觉

- 8pt 栅格：4 / 8 / 12 / 16 / 24 / 32
- 卡片内边距 16，卡片间距 24，页面左右 32
- 圆角：卡片 12，面板 16，按钮 8
- 阴影只保留一级；**禁止**卡片内再套卡片（用分组标题代替）

## 7. 动效

- 120–200ms，ease-out；只用于出现 / 消失 / 状态切换
- **禁止**：装饰性漂浮、循环动画、同屏超过 2 个动画
- 列表进场只播首批，刷新不重播（沿用现有 stagger 守卫）

## 8. `ui/` 组件规范

| 组件 | 规格 |
|---|---|
| Button | primary / secondary / ghost / icon；高度 32（小）36（常规）|
| Badge | 中性 / 琥珀 / 红 / 靛蓝 四态，文字 ≤ 6 字 |
| Table | 列 ≤ 6；超出进详情页；支持行内 1 个主操作 + 1 个更多菜单 |
| Toolbar | 搜索 + 筛选 + 批量，控件 ≤ 4 |
| EmptyState | 图标 + 标题（14px）+ 按钮，总高 ≤ 200px |
| Stat | 数值 + 标签，可选趋势小字（≤ 8 字）|

## 9. 反模式（评审直接打回）

1. 一屏出现 > 3 种字号
2. 一屏出现 > 2 个主色按钮
3. 卡片里放段落文字
4. 表格单元格里放长句
5. 连续 3 行以上说明文字
6. 用颜色表达"成功"
7. 用分割线代替间距
8. 图标 + 文字重复表达同一件事

## 10. 截图自检 5 问（每页验收必答）

1. 3 秒内能说出这页在讲什么吗？
2. 主行动在哪个位置？是否唯一？
3. 有没有超过 2 行的说明文字？
4. 有没有纯装饰元素可以删掉？
5. 这一屏里，数字是否比文字多？
